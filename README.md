Solmar is an original top-down 2D open-world crime game: the coastal city of Solmar, drivable traffic, pedestrians, a wanted system with police response, a five-mission story, combat, a HUD with a minimap, a start screen and saves. `main.ts` hands the game in (copies `game/` and `screenshots/` to `/output` with a `dossier.json` summary); play it locally with `node serve.ts` on http://localhost:8080.

## Run it

```sh
node main.ts
```
